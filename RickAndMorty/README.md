# Rick and Morty (starter)

Demo de clase: consumir una API REST con Retrofit.
TC2007B · Módulo 3 · Desarrollo Móvil (Android).

## Qué ya está hecho

- Lista de personajes y pantalla de detalle con imagen grande, conectadas con Navigation.
- Los datos vienen de `getPersonajes()`, una lista fija de 3 personajes en `model/Personaje.kt`.
- Ya están agregadas las dependencias de Retrofit, kotlinx.serialization y Lifecycle, y el permiso INTERNET.

Corre la app: ya funciona con los datos fijos.

## Qué hacemos en el demo

Traer los personajes de https://rickandmortyapi.com con Retrofit, un repositorio y un ViewModel.
